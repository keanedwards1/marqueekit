# MarqueeKit

MarqueeKit is a lightweight toolkit for creating smooth, responsive image marquees for modern websites.

## Motivation

Image marquees can be surprisingly difficult to build well. MarqueeKit provides a polished starting point for seamless scrolling, with a simple setup and room for customization.

## Quick Start

Install the project dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Usage

Use the examples and documentation in the running app to explore MarqueeKit:

- `/docs` — setup and integration guidance
- `/examples` — working marquee examples
- `/pricing` — available MarqueeKit options

To customize the site, edit the files in `src/app` and `src/components`. The development server automatically reloads when files change.
